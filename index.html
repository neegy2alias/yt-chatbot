Chat with a model running on your own machine

Works in Chrome, Edge, Firefox and Safari — on any graphics card, or none. It uses your GPU (WebGPU) when available and falls back to your CPU automatically.

Pick a model and press Load model. The first load downloads the weights and caches them; after that it starts instantly. Nothing you type leaves this device.

CPU mode is slower than GPU — if it feels sluggish, try a smaller model.
